# Introdução a Testes Unitários em C#

Este repositório é destinado ao aprendizado e introdução de **testes unitários** em **C#**. Ele apresenta o conceito de testes de software e como implementar testes unitários para garantir a qualidade do código, com exemplos práticos usando o framework **xUnit**.

## Funcionalidades Implementadas

Este repositório contém exemplos simples de código em C# para ensinar os seguintes conceitos:

- **Testes Unitários**: Validação de funções isoladas.
- **Assertivas Básicas**: Verificação de resultados esperados.
- **Mocking**: Simulação de comportamentos e objetos no código.
  
## Testes Implementados

O foco deste repositório é a introdução ao **teste unitário** usando **xUnit**. Os testes abrangem as seguintes áreas:

- **Testes de Funções Simples**: Validar funções matemáticas ou de lógica simples.
- **Testes de Métodos de Classe**: Verificar o comportamento de métodos em diferentes cenários.
- **Uso de Mocking**: Criar objetos falsos para simular dependências.
